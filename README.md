# Microsoft Clarity for PrestaShop - Free Integration Module (m4p_msclarityfree)

**Free PrestaShop module** that integrates your store with **[Microsoft Clarity](https://clarity.microsoft.com/)** - a free behavioral analytics tool with **heatmaps, session recordings and user behavior insights**. Install, paste your Clarity Project ID and start watching how visitors really use your shop.

Compatible with **PrestaShop 1.7.x and 8.x**.

## What is Microsoft Clarity?

Microsoft Clarity is a free website analytics tool that shows you **how real visitors behave in your store** - not just numbers, but actual behavior:

- **Heatmaps** show which elements of a page get clicked, how far users scroll and which content they ignore. Perfect for optimizing product pages, category pages and the checkout.
- **Session recordings** let you replay anonymized visits step by step - you can see exactly where a customer got confused, what they searched for and why they abandoned the cart.
- **Behavior insights** automatically detect problems such as *rage clicks* (frantic clicking on an element that does not respond), *dead clicks* (clicks on non-clickable elements) and *excessive scrolling*.
- **No traffic limits and no fees** - unlike most heatmap tools, Clarity is completely free with unlimited recordings.

Clarity works alongside Google Analytics and does not slow the page down - the tracking script loads asynchronously.

## What does this module do?

The module injects the official Microsoft Clarity tracking script into every front-office page of your PrestaShop store. No template editing, no manual code pasting, no developer needed:

1. You create a free project in the Clarity panel.
2. You paste the **Project ID** into the module configuration.
3. You flip the switch to *On* - done. Data appears in your Clarity dashboard within minutes.

You can disable tracking at any time with a single switch, without uninstalling the module.

## Installation

1. Download the latest release as ZIP.
2. In your PrestaShop admin go to **Modules → Module Manager → Upload a module** and upload the ZIP.
3. Open the module configuration, switch **Active module** to *On*.
4. Paste your **Clarity Project ID** (Clarity panel → *My Projects* → gear icon → *Project ID*) and save.

That's it - data will start appearing in your Clarity dashboard within minutes.

## Configuration

| Setting | Description |
|---|---|
| **Active module** | Turns Clarity tracking on/off on the front office |
| **Project ID Clarity** | Your project identifier from the Microsoft Clarity panel |

## Requirements

- PrestaShop 1.7.0 - 8.1.x
- PHP 7.3+
- A free [Microsoft Clarity](https://clarity.microsoft.com/) account

Microsoft Clarity collects behavioral data for analytics purposes. Remember to list it among **analytical cookies** in your store's cookie/GDPR consent policy.
